# 주간 리뷰 가이드

매주 훈련 후(일요일 권장) **5분** 안에 확인하는 체크리스트입니다.  
웹 로거 **주간 리뷰** 탭과 함께 사용하세요.

## 1. 80%+ 볼륨 확인

| 지표 | 참고 기준 | 조정 방향 |
|---|---|---|
| 스내치 80%+ reps | 주 15–25 reps | 20+ → 증량 또는 유지 / 15 미만 → 70–75% 볼륨 보강 |
| C&J 80%+ reps | 주 10–20 reps | 15+ → 유지 또는 소폭 증량 / 10 미만 → 클린·저크 포지션 위주 |

## 2. PR / 테스트

- 이번 주 새 PR 또는 테스트 시도가 있었는지
- 메모에 `PR`, `테스트` 키워드를 적으면 주간 리뷰에 자동 표시됨

## 3. 컨디션

- 수면, 부상/통증, 피로도
- 불편 메모가 있으면 **무게 증량보다 회복·mobility 우선**

## 4. 다음 주 조정 메모 (예시)

```
1주차: 스내치 80%+ 볼륨 양호. C&J 저크 캐치 발 간격 집중. 다음 주 C&J 2.5kg 증량.

2주차: 스내치 PR 87.5kg 성공. C&J 80%+ reps 충분. 다음 주 유지 후 3주차 소폭 증량.

deload: 4주 연속 고강도 → 다음 주 70% 이하, reps 50% 감소
```

## 2주 시범 기록 요약

설정 → **2주 시범 데이터 불러오기** 후 주간 리뷰에서 확인할 수 있는 내용:

| 주 | 기간 | 스내치 80%+ | C&J 80%+ | 하이라이트 |
|---|---|---|---|---|
| 1주차 | 6/30 – 7/6 | 22 reps | 10 reps | C&J 저크 캐치 이슈, deload 전 |
| 2주차 | 7/7 – 7/13 | 26 reps | 18 reps | 스내치 87.5kg PR, deload 후 회복 |

## 일일 기록 최소 형식

메인 리프트만 기록해도 충분합니다:

- 무게 **또는** % (TM 기준 자동 변환)
- 세트 × 반복
- 성공 rep / 실패 rep
- 한 줄 메모 (테크닉, PR 등)

보조운동은 선택 — 헬스 앱에 따로 기록해도 됩니다.
