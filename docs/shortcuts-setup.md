# 아이폰 단축어 세팅 (코칭 연동)

목표: Rise / Fitness 데이터를 에이전트가 **공유앨범**에서 읽을 수 있게, 운동 후 **한 번 탭**으로 올리기.

공유앨범: `RISE 운동기록`  
링크: `https://www.icloud.com/sharedalbum/#B22GWZuqDHkpFVq`  
채팅 신호: **「앨범 봐봐」** 또는 **「올려둠」**

---

## 0. 준비 (한 번만)

1. **사진** 앱 → 앨범 → **공유 앨범** `RISE 운동기록`이 있는지 확인  
   - 없으면 새로 만들고, 위 스트림과 동일하게 쓰거나 기존 앨범 유지
2. **설정 → 단축어 → 고급**
   - 필요 시: 공유시트 허용, (Health 쓸 경우) 건강 데이터 허용
3. **설정 → 개인정보 보호 → 건강** 에서 단축어에 운동 읽기 허용 (단축어 B용)

---

## A. Rise용 — 「운동 기록 올리기」

Rise는 외부 API가 없어서 **스크린샷 → 공유앨범**이 가장 안정적입니다.

### 동작
1. Rise에서 세션 요약 화면 연 뒤 **스크린샷** (필요하면 스크롤해서 2장)
2. 단축어 **「운동 기록 올리기」** 실행
3. 최근 사진이 공유앨범에 들어감
4. 채팅에 **「앨범 봐봐」** 한 줄

### 단축어 만들기 (아이폰)

1. **단축어** 앱 → **+** → 이름: `운동 기록 올리기`
2. 동작 추가 순서:

| 순서 | 동작 (검색어) | 설정 |
|------|----------------|------|
| 1 | `사진 선택` 또는 `최근 사진 찾기` | **최근** / 개수 **2** (또는 실행 시 묻기) |
| 2 | `앨범에 추가` / `공유 앨범에 추가` | 앨범: **RISE 운동기록** |
| 3 | (선택) `알림 표시` | 문구: `공유앨범에 올렸습니다. 채팅에 「앨범 봐봐」` |

3. 세부 팁
   - **「사진 선택」**이 더 안전: 올릴 장만 고름  
   - **「최근 N장 자동」**은 편하지만 다른 사진이 섞일 수 있음 → 처음엔 **선택** 권장
4. **홈 화면 / 공유 시트 / 뒤로 탭**에 추가해 두면 Rise 직후 바로 실행 가능  
   - 단축어 하단 **공유** → 홈 화면 추가  
   - 또는 **공유 시트에 표시** ON → 사진 앱에서 공유 → 이 단축어

### 더 빠른 변형 (숙련 후)
- `스크린샷 찍기` → `앨범에 추가`  
  - Rise 화면이 보이는데 단축어를 제어센터/백탭으로 실행해야 함  
  - 제어센터에 단축어 넣거나 **설정 → 손쉬운 사용 → 터치 → 뒤로 탭 → 이중 탭 → 단축어**

---

## B. 러닝용 — 「러닝 요약 복사」

Apple Fitness / 운동 앱 기록은 Health에서 숫자로 뽑을 수 있습니다.  
에이전트는 Health에 직접 못 들어가므로, **요약을 복사 → 채팅에 붙여넣기**가 제일 빠릅니다.  
(스크린샷을 앨범에 같이 올려도 됨)

### 단축어 만들기

1. 이름: `러닝 요약 복사`
2. 동작 예:

| 순서 | 동작 | 설정 |
|------|------|------|
| 1 | `운동 찾기` (건강) | 운동 종류: **달리기** / 정렬: 시작일 최신 / 제한 **1** |
| 2 | `반복` (각 운동) | 아래 텍스트 조합 |
| 3 | `텍스트` | 템플릿 (아래) |
| 4 | `클립보드에 복사` | |
| 5 | (선택) `알림` | `러닝 요약 복사됨. 채팅에 붙여넣기` |

### 텍스트 템플릿 예시

```text
날짜: [운동 시작일]
거리: [운동 거리] km
시간: [운동 시간]
칼로리: [운동 소모 에너지]
평균심박: [운동 평균 심박수]
```

단축어 편집기에서 **마법 변수**로 운동 필드 삽입.  
페이스는 단축어 버전에 따라 직접 계산이 필요할 수 있음 → 없으면 거리·시간만이라도 충분.

### 앨범에도 남기고 싶을 때
- Fitness 요약 화면 **스크린샷** → 단축어 A (`운동 기록 올리기`) 실행  
- 또는 채팅에 요약 붙여넣고 **「러닝도 반영해줘」**

---

## C. 하루 루틴 (추천)

| 상황 | 할 일 |
|------|--------|
| 헬스 (Rise) | 스크린샷 → `운동 기록 올리기` → 채팅「앨범 봐봐」 |
| 러닝 (Fitness) | `러닝 요약 복사` → 채팅 붙여넣기 **또는** 스크린샷+앨범 |
| 인바디 | 결과 화면 스크린샷 → 같은 앨범 |

---

## 안 되는 것 (기대치)

- Rise / Fitness 앱을 에이전트가 **몰래 자동 스크래핑** → 불가
- 단축어만으로 Cursor 채팅에 **완전 자동 전송** → 보통 불가 (메시지 자동화는 제한적)
- 공유앨범 업로드까지 자동화한 뒤 **「앨범 봐봐」한 줄**이 가장 안정적
