# 역도 기록 방식 선택

## 선택한 방식: 하이브리드 (웹 로거 + 시트 템플릿)

| 구분 | 도구 | 용도 |
|---|---|---|
| 메인 리프트 | [웹 로거](../index.html) | 스내치/C&J — % 자동 계산, O/X, 메모 |
| 백업/공유 | [Google Sheets CSV 템플릿](../templates/daily-log-template.csv) | 코치 공유, 장기 보관 |
| 테크닉 | 휴대폰 영상 | 실패 rep만 촬영 (앱 외부) |
| 보조운동 | 기존 헬스 앱 (Hevy/Strong) | 스쿼트·RDL 등 세트×반복 기록 |

## 선택 이유

1. **% 기반 프로그램**과 궁합이 좋음 — TM 입력 한 번으로 kg ↔ % 자동 변환
2. **입력 부담 최소** — 메인 리프트만 30초 내 기록
3. **주간 80%+ 볼륨** 자동 집계 — deload/증량 판단에 바로 사용
4. **오프라인 동작** — localStorage 저장, JSON 내보내기/가져오기

## 상황별 사용법

- **혼자 훈련**: 웹 로거만으로 충분
- **코치에게 공유**: CSV 내보내기 → Google Sheets 업로드
- **대회 준비**: 주간 리뷰 탭에서 80%+ 볼륨 + PR 확인
- **입문**: 영상 + 한 줄 메모만 먼저 → 익숙해지면 숫자 기록 추가
